## 2. 平台 A：腾讯云 CloudBase 云托管（备选：真 Serverless、不买服务器、国内快、需 ¥19.9/月）

> 2026-08-10 实测更新：CloudBase 已于 2026 改版，**不再有独立的「按量计费」环境入口**，改为套餐制：**免费体验版(0) / 个人版(¥19.9/月) / 标准版(¥199/月) / 企业版(¥999/月)**。原首选 Zeabur 也改为「须买 VPS 或自带服务器」。CloudBase 仍是「不买服务器」里技术最优（国内上海直连 RDS 低延迟），但**最低付费档是个人版 ¥19.9/月，没有「0 月费跑容器」档**。因用户坚持零成本，本项目最终选 Render 免费层（见平台 B），CloudBase 留作付费备选。

1. 注册/登录 [腾讯云](https://cloud.tencent.com) → 进入 **CloudBase 云开发** 控制台。
2. 新建环境 → **套餐选「个人版」（¥19.9/月，最便宜的付费档）**；地域选 **上海**（云托管仅开放上海）。
   - ⚠️ **不要选「免费体验版」**：官方规定免费体验版不支持开启按量付费，**无法开通云托管**（本看板必须跑云托管容器）；且其自带 PostgreSQL/云函数/AI Agent 与本项目阿里云 RDS 无关。
   - 若开通界面默认只显示免费体验版：先建免费体验版环境，进入后点「升级为付费环境 / 调整为付费套餐」→ 选个人版，再开云托管。
3. 进入 **云托管** → **新建服务**（服务名称随意，如 `cli-dashboard`）。
4. 新建版本 → 上传方式选 **「代码库拉取」** → 代码源连 **GitHub** 仓库 `xiaohuoshuan123/cli-dashboard`（main 分支）。
   - CloudBase 会自动按仓库根 **`Dockerfile`**（已写好 `node:20-alpine`，监听 3000）构建镜像；无需手写 YAML。
5. 监听端口填 **3000**；流量策略默认 100%。
6. **环境变量** 填第 1 节全部变量（控制台「环境变量」配置）；`DB_PASSWORD`/`ACCESS_TOKEN` 设为保密。
7. 开始部署 → 部署成功配置流量 100% → 跳到第 6 节加白名单、第 7 节验证。
8. 默认分配 `*.apigw.tencentcs.com` 域名（可绑自定义域名 + 自动 HTTPS）。

> 费用：个人版 ¥19.9/月固定订阅 + 云托管按资源点（CPU/内存/流量，缩容到 0 时不计费）。比买服务器低一个数量级，但**非免费**。

## 3. 平台 B：Render 免费层（★ 当前选定：零成本、不买服务器、海外偏慢）

> 2026-08-10 最终选型：用户要求「不买服务器 + 零月费」，Render 免费层满足（Node 容器，代码零改动，**仓库 `render.yaml` 已就绪**）。代价：部署在**海外**（已设 `region: singapore`，海外中离国内最近），与国内阿里云 RDS 跨地域握手慢——实测冷连接 ~12s，稳态经连接池预热后降至 ~1s；冷启动/休眠唤醒仍可能偏慢。免费层 15min 无访问休眠、冷启动 30–60s、每月 750 实例小时（单机常驻够用）。

1. 注册 [render.com](https://render.com)（免费层免信用卡或 $1 预授权，可退）。
2. New → **Web Service** → 连 GitHub 仓库 `xiaohuoshuan123/cli-dashboard`（main）。
   - 仓库根 `render.yaml` 自动识别：runtime node / plan free / build `npm install` / start `npm start` / healthCheck `/api/health` / region singapore。也可在控制台手动填。
3. **Environment**（控制台手动加敏感变量，勿写进仓库）：填第 1 节全部变量。
   - 尤其 `DB_PASSWORD`（Railway 导出真实值）、`ACCESS_TOKEN`（线上值 `35253b491a2ca076ec3466923c0b9f4c66f627342b52a87d`）、`TZ=Asia/Shanghai`。
   - `PORT` 由 Render 自动注入，勿手填。
4. 部署（构建约 2–5 分钟）→ 生成 `*.onrender.com` 免费域名（可绑自定义域名 + 自动 HTTPS）。
5. 跳到第 6 节加白名单、第 7 节验证。

## 6. 阿里云 RDS 白名单（多数情况可跳过）

- 实测从本机 IP `183.208.208.45` 能连到 RDS（握手成功），**说明白名单很可能已放行外部连接**。
- 若新平台部署后报 `ECONNREFUSED` / `Access denied` / 连接超时：
  1. 阿里云控制台 → RDS → 实例 `rm-bp1m4fy8d66u3c6xmbo` → **白名单设置**。
  2. 查新平台出口 IP（CloudBase 上海 / 腾讯云 / 轻量云为固定 IP；Render 相对固定）。
  3. 把新 IP 加入白名单分组。**保留 Railway IP 直到迁移稳定**。
- 验证：看新平台部署日志，确认 mysql2 连接无 `ECONNREFUSED` / `Access denied`。
