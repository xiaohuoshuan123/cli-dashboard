## 2. 平台 A：Zeabur（★ 推荐，零改动、亚太节点、国内快）

1. 注册 [zeabur.com](https://zeabur.com) → 绑定 GitHub。
2. New Project → 选仓库 **`xiaohuoshuan123/cli-dashboard`**（main 分支）。
3. 服务类型选 **Node.js**（自动识别 `package.json`，执行 `npm install` + `npm start`）。
4. **Variables** 填入第 1 节全部变量；`DB_PASSWORD`/`ACCESS_TOKEN` 标记为 Secret。
5. Zeabur 自动注入 `$PORT`，无需改代码。
6. Networking → 生成免费 `*.zeabur.app` 域名（或绑自定义域名）。
7. 部署完成后跳到第 4 节加白名单、第 5 节验证。

> Zeabur 也能用仓库里的 `Dockerfile`（容器模式），默认走原生 Node 构建即可。

## 3. 平台 B：Render（快速迁走，海外偏慢，免费层会冷启动）

1. 注册 [render.com](https://render.com) → New → **Web Service** → 连 GitHub 仓库。
2. Build Command `npm install`，Start Command `npm start`，选 **Free** 计划。
3. 仓库根的 `render.yaml` 可自动识别；或在控制台 Environment 手动填第 1 节变量。
4. 部署后跳到第 4 节、第 5 节。
5. 注意：免费层冷启动 30–50s，首次打开慢；可升级 $7/月 Starter 消除休眠。

## 4. 平台 C：腾讯云 CloudBase 云托管（国内、快，需 Dockerfile）

1. 腾讯云控制台 → **CloudBase** → 云托管 → 新建服务。
2. 代码源选「代码仓库(GitHub)」或「本地上传」，使用仓库根 **`Dockerfile`**（已写好 node:20-alpine）。
3. 环境变量填第 1 节（控制台「环境变量」配置）。
4. 服务端口填 **3000**。
5. 部署后跳到第 5 节验证（如连不上 DB 再回第 4 节加白名单）。

## 5. 平台 D：国内轻量云 + Coolify（最可控，¥30–60/月）

1. 购腾讯云/阿里云轻量应用服务器（2C2G），装 Docker。
2. 装 Coolify：`curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash`。
3. Coolify 连 GitHub 仓库 → 新建 Node 服务（或用仓库 `Dockerfile`）→ 填第 1 节变量。
4. 绑定域名 + 自动 HTTPS，跳到第 5 节验证。

## 6. 阿里云 RDS 白名单（多数情况可跳过）

- 实测从本机 IP `183.208.208.45` 能连到 RDS（握手成功），**说明白名单很可能已放行外部连接**。
- 若新平台部署后报 `ECONNREFUSED` / `Access denied` / 连接超时：
  1. 阿里云控制台 → RDS → 实例 `rm-bp1m4fy8d66u3c6xmbo` → **白名单设置**。
  2. 查新平台出口 IP（Zeabur/腾讯云/轻量云为固定 IP；Render 相对固定；Fly/Koyeb 可能动态）。
  3. 把新 IP 加入白名单分组。**保留 Railway IP 直到迁移稳定**。
- 验证：看新平台部署日志，确认 mysql2 连接无 `ECONNREFUSED` / `Access denied`。

## 7. 部署后验证（必做）

1. 打开看板首页（或 `GET /api/health` 应返回 `{"status":"ok"}`）。
2. 调一条需令牌的接口，例如：
   ```
   curl -H "x-api-token: <你的ACCESS_TOKEN>" https://<新域名>/api/tasks/plan-names
   ```
   应返回 7 个计划名称的数组。
3. 核对数据是否与 Railway 旧实例一致（设备数、任务完成情况）。
